第一部分：日常训练周完成的工作

周一至周五训练周期
🎯

教练·独立完成的工作

12 项 · 核心产出：战术设计 + 选手培养 + 训练管控

C-01战术风格与体系设计

P0每月
根据选手特点确定队伍战术风格，制定赛季战术路线图，明确每张地图战术核心理念，每月评估适配性
KPI：战术本完整度（5图×2方）= 100%

C-02选手角色手册编写

P0每季度
为每个位置编写角色手册：IGL→指挥节奏/信息整合；狙击手→关键局打开/区域封锁；步枪手→执行/补枪；自由人→信息/非常规
KPI：5个角色手册按时交付 = 100%

C-03战术本维护与更新

P0每次新增
命名规则：完成战术本基建后，新增的战术：地图缩写名_T/CT.docx，24小时内更新完毕，领队检查与战术总表完全匹配
KPI：战术本与总表匹配率 = 100% 超24h未更新 = 不合格

C-04选手短板识别与教导

P0每日
识别薄弱环节（枪法/道具/走位/决策/信息），制定训练计划，跟踪改善进度
KPI：选手短板改善率 ≥ 70%/月

C-05低级失误识别与纠正

P0每场
6类失误分类（交流/道具/走位/战术素养/经济/时间管理），分级处理（A致命/B严重/C一般）
KPI：A/B级低级失误率 ≤ 3次/场 同一选手同类失误3次+ = 启动专项纠正

C-06训练赛战术安排

P0每日
明确每局训练目标，安排战术执行方案，赛中指挥与调整
KPI：训练赛战术执行率 ≥ 85%

C-07Demo 复盘分析

P1每场
训练赛后复盘≥30分钟，重点复盘执行失败的战术、个人失误、关键回合逐帧分析
KPI：赛后复盘完成率 = 100%

C-08对手情报收集与分析

P1每周
跟踪主要对手近期比赛结果和战术变化，赛前情报简报，对手Demo分析
KPI：对手情报更新频率 ≥ 1次/周

C-10地图池规划

P1每赛季
维持5张主力地图+1-2张备选，评估地图池适配性，根据版本调整
KPI：主力地图5张×2方完整战术体系

C-11经济管理策略制定

P1每月
明确各经济情况下的购买策略（全购/半购/ECO/强起），连败止损方案
KPI：每图经济策略表覆盖率 = 100%

C-13一对一沟通与选手管理

P0每周
对问题选手面对面聊天，给出警告和建议，记录沟通内容，连续未改善→书面警告→改善不理想→下方+换人
KPI：一对一沟通完成率 = 100% 问题选手漏沟通 = 不合格

C-14选手综合评估打分

P0每周/每月
周度7维度评分+月度5维度百分制，作为末位淘汰依据
KPI：选手评估表填写率 = 100%

领队·独立完成的工作

12 项 · 核心产出：数据录入 + 后勤保障 + 文档归档

M-01训练简报填写

P0每日
训练结束后30分钟内完成腾讯文档「UR_CS2_训练日志」的更新

M-02训练赛数据维护

P0每日
训练赛结束后30分钟内完成JSON文件上传，同时查看每日简报/训练日志在网页端的赛训汇总报告的准确性
KPI：数据上传准时率 = 100% KPI：数据准确率 ≥ 98%

M-03训练考勤与纪律管理

P0每日
训练时段出勤监控，迟到/缺席记录，训练期间纪律监督

M-04录像命名与归档

P1每场
按命名规则（日期_对手_地图.FLV）重命名并归档至局域网 02_录像/
KPI：录像命名规范率 = 100%

M-05队员个人信息表维护

P1人员变动时
20列字段维护（含多Steam账号、Faceit/5E ID、手机号、紧急联系人等）
KPI：人员变动后24h内同步

M-07外设库存管理

P1每周
外设库存表维护（型号/数量/在用/备件），损坏登记与返修流程
KPI：外设库存周更新 = 100%

M-08生活保障

P1每日
基地餐饮/饮水/零食补给，住宿问题响应，办公区域整洁维护
KPI：生活问题响应 ≤ 2小时

M-10财务与预算管理

P2每月
月度成本报表填写，补给审批（≤500领队审批），费用报销整理
KPI：月度成本报表月末交付 = 100%

M-11应急处理

P1即时
6类突发场景处理（请假/设备故障/CS2崩溃/情绪冲突/比赛争议/签证问题）
KPI：设备故障响应 ≤ 15分钟

M-12局域网文件归档

P1每周
检查所有文件命名规范性、补漏、确保存储位置正确
KPI：文件归档规范率 = 100%

M-13赛训数据同步检查

P1每日
17:30自动同步后检查ur-esports.cn数据完整性，异常反馈
KPI：数据异常发现后2h内反馈

M-14文档归档与周报

P1每周
赛训汇总报告（按周）、月度成本报表整理
KPI：周报周五交付 = 100%

第三部分：每周六例会

约40分钟 · 教练+领队双向汇报

📋 例会定位

每周六上午固定召开，参会人：教练HZ + 领队Smokkky（必要时邀请赛训总监aiwazap列席）。
目的：信息对齐 · 问题暴露 · 决策推进 · 行动落地，不是汇报流水账，而是聚焦问题和决策。
⚠️

教练·需着重指出的问题

🎯战术执行与体系问题

  • 战术执行率不达标：哪些图/哪方执行率低？原因分析（选手不执行/战术本身有缺陷/对手针对）
  • 战术体系适配性：当前战术风格是否适配选手阵容？是否需要调整方向？
  • 新战术测试结果：本周测试了哪些新战术？可行性评估？需要修改还是淘汰？

👤选手个人问题

  • 短板未改善：上周指出的短板，本周有无进展？需要调整训练方案吗？
  • 低级失误反复：同一选手同类失误出现3次+，是否需要升级处理（专项纠正/书面警告/约谈）
  • 态度/情绪问题：训练态度消极、不执行战术、场上情绪失控、队内冲突
  • 末位淘汰预警：月度评分偏低选手，是否需要启动淘汰/引援流程

🎮训练质量与对手分析

  • 训练赛质量评估：本周训练赛对手等级（S/A/B）分布、战术执行情况、态度问题
  • 练图策略调整：当前弱图/强图，下周需要重点练哪张图？为什么？
  • 对手情报更新：本周收集了哪些对手信息？下周约战建议（约谁/练什么）
⚠️

领队·需着重指出的问题

📊数据与文档问题

  • 三表数据异常：训练日志/JSON数据/战术总表有无不一致？哪些数据需要修正？
  • 赛训数据同步异常：ur-esports.cn数据是否完整？有无缺失/错误？
  • 文件归档问题：录像/战术本/文档是否有未命名/未归档/存储位置错误？

🏠后勤与保障问题

  • 设备故障：本周有无设备故障？处理结果？是否需要采购/返修？
  • 生活保障：餐饮/住宿/外设补给有无问题？选手有无生活方面诉求？
  • 财务预算：本月费用是否超预算？是否需要审批额外采购？

👥人员与纪律问题

  • 考勤异常：本周有无迟到/缺席/请假？频次？是否需要升级处理？
  • 选手违规：训练期间直播/娱乐/不专注等违规行为，是否需要上报/警告
  • 人员变动：试训队员进展？是否需要引援？有无离队意向？
📅

周六例会·会议大纲（约40分钟）

0-3 min

开场与上周行动项回顾

主持人：教练 HZ
  • 回顾上周例会的行动项，逐条确认完成状态
  • 未完成的行动项：说明原因 + 重新排期
3-12 min

教练汇报：本周训练与战术

汇报人：教练 HZ（9分钟）
  • 训练赛总结：本周训练赛场次/对手/结果/战术执行率/态度评分
  • 选手状态评估：5人周度评分简报（亮点+问题+下周目标）
  • 短板与失误：本周新发现短板 + 低级失误统计 + 处理方案
  • 战术体系：新战术测试结果 + 战术本更新情况 + 匹配校验结果
12-18 min

领队汇报：本周数据与保障

汇报人：领队 Smokkky（6分钟）
  • 数据情况：三表完整度/数据准确率/同步异常/归档状态
  • 考勤纪律：出勤率/迟到缺席/违规记录
  • 后勤保障：设备状况/生活补给/财务支出/外设库存
  • 人员变动：试训进展/引援需求/其他人员事项
18-30 min

⚠️ 问题讨论与决策（核心环节）

双方讨论（12分钟）
  • 优先讨论P0问题：选手态度/队内冲突/训练质量不达标
  • 选手处理决策：书面警告？专项纠正训练？约谈？淘汰预警？
  • 训练策略调整：下周练图方向？约战对手？新战术优先级？
  • 需要上报赛训总监的事项：确认上报内容/时间/方式
30-37 min
