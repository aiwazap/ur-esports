## 3. 数据源（四路汇入一库）

数据库：`backend/data/ur_esports.db`（SQLite，40+ 表）。**生产库是唯一权威，数据只允许 生产→本地 单向拉取，严禁反向。**

1. **手工录入**：网页表单（选手/比赛/战术/试训/装备等模块）
2. **腾讯文档同步管道**：`POST /api/internal/sync-tencent`（仅限 localhost 调用）→ tencent_sync 目录的 CSV → 转 XLSX → `scripts/sync_tencent_api.py` ETL 入库；训练日志/每日简报/战术总表走此路
3. **FACEIT 官方 API**（`open.faceit.com/data/v4`，Bearer Key 鉴权）：`/api/faceit-sea/sync-players` 拉当前 ELO，`/sync-matches` 拉比赛+逐场统计（近 N 场滚动窗口，upsert 幂等）；注意 API 拿不到逐场 ELO 变化，faceit_match_players.elo_delta 对真实数据恒为 0
4. **Excel/Word 导入**：xlsx 解析（比赛数据等批量导入）

核心表速览：players/matches/player_stats（选手与比赛）、tactics_v2（战术库 139 套：地图/T-CT/回合类型 P-A-H-F-E/步骤 JSON）、training_logs_v2 系列（训练）、faceit_*（FACEIT 模块 5 表）、trial_*（试训）、users（登录，admin 为 role='admin'）、hltv_*（对手情报）。

选手照片在 `backend/uploads/avatars/`（gitignore 排除；DB 里 players.avatar_url 引用相对路径）。

## 4. 设计逻辑（视觉与代码约定）

**设计语言**（主载体 `frontend/src/pages/overview-v8.css`）：
- 底色近黑深蓝（body #05070b 渐变 + 青/蓝辉光团；页面容器 #050a1d→#04081a），卡片 rgba(13,22,60,.85) 渐变、1px 蓝边 rgba(80,120,255,.3)、圆角 12px、hover 亮边
- 主强调渐变 #2563eb→#7c3aed（按钮/激活态），青色渐变字 #4fa8ff→#38e5ff（标题），语义色：胜 #34d399 / 负 #f87171 / 平 #f97316 / 金色赛事 #d4af37
- 文字四级：#e9efff / #aebbe4 / #8fa5d8 / #7288bd；数字一律 tabular-nums；中文系统字体栈（PingFang SC/微软雅黑）
- 动效克制：顶栏流光线、扫描光、卡片淡入；全站支持 prefers-reduced-motion 降级
- **换肤范式**：`faceit-sea.css` 用 CSS 变量整体覆盖出 FACEIT 黑橙主题——做平台/模块专属皮肤照抄此法
- 布局：fixed 72px 顶栏（左品牌/中导航/右操作），页面横向 padding 28px，卡片 grid gap 16-20px

**代码约定**：路由模块化（backend/routes/ 一域一文件，路由内 CREATE TABLE IF NOT EXISTS 自建表）；前端一页一 jsx + 页面级 css；API 相对路径 /api（vite 代理开发、同源生产）；CORS 白名单制（server.js ALLOWED_ORIGINS，新环境记得加）。

## 5. 华哥的设计偏好（重要，做新功能前必读）

- **视觉**：暗色电竞风但要"高级、克制"——反感堆特效；喜欢发光/霓虹但低强度；UR=蓝青系、RVN=黑紫金系，**两个品牌严禁撞色**（RVN 站禁用青色）；地图等实体要有专属识别色
- **动效**：追求"视频般丝滑"的质感；60fps、无缝循环；叙事性动效欣赏"史官笔法"式的克制表达，不要煽情
- **文档输出**：微软雅黑、1.5 倍行距、层级分明带大纲/目录、颜色区分类别、内容块不跨页拆散；讨厌拼写检查波浪线（导出要 noProof）
- **交互**：极度重视"一键"——一键导出/一键启动（bat 双击文化）；不想记命令行
- **协作**：简体中文；Markdown 列表汇报，禁 HTML table；不懂技术，要求先复述理解并确认再动手；重要操作必须先备份、保留回滚路径；生产改动必须他明确下令
- **数据**：越详尽越好；来源要可追溯（data_source 字段习惯）；敏感内容只记摘要、原件另存

## 6. 构建与部署

**本地首次运行**：backend 与 frontend 各 `npm install` → 补 `backend/.env`（见 §2）→ 双击 `启动本地站.bat`。admin 账号见生产库（本地副本 admin/admin123）。

**生产部署（当前现实）**：本地 `npm run build` → scp 上传 dist 整包 + 改动的后端文件 → `pm2 restart ur-esports`。
⚠️ **重大注意（2026-07-14 状态）**：生产运行的代码源自 codex worktree 的**未提交工作区**+Claude 侧修复，不在任何 git 提交里。`deploy.sh`（git pull + 重建）会把网站回退，**在 codex 完成提交合并前禁止使用**。
