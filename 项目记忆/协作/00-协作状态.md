# 00-协作状态

## 协作路径说明（永久规则，所有项目通用）

- `项目记忆\协作\` 是 Claude/Codex 协作的固定入口，路径规则对所有项目统一：
  - `00-协作状态.md` —— 入口，先读这个，唯一状态真相源
  - `01-Claude方案.md` —— Claude 执行前的方案，等 Codex 复核
  - `02-Claude实施记录.md` —— Claude 执行后的记录，含测试结果/证据
  - `03-Codex审核结果.md` —— Codex 复核意见落这里（APPROVED / CHANGES_REQUIRED + 理由）
  - `04-待Codex处理.md` —— 需要 Codex 处理/拍板的问题清单
  - `05-最终验收.md` —— 双方确认的最终验收结论
- 施工规格存档：`项目记忆\规格与施工说明\`
- 权威内容始终以本项目目录下的实际文件为准；Codex 自己的"项目名+review"工作副本仅供参考，复核请直接读这里

状态：**IDLE —— 尚无进行中的协作任务**

当有新任务开工时，按以下流程更新本文件并联动其余文件：

1. Claude 写 `01-Claude方案.md`，本文件状态改为 `WAITING_REVIEW`
2. Codex 审核意见写进 `03-Codex审核结果.md`；若需返工，状态改 `CHANGES_REQUIRED`
3. Claude 执行后写 `02-Claude实施记录.md`
4. 需要 Codex 处理/拍板的问题列进 `04-待Codex处理.md`
5. 双方确认收尾后写 `05-最终验收.md`，本文件状态改回 `DONE` 或 `IDLE`
