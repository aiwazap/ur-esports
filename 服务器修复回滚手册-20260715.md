# 服务器修复回滚手册（2026-07-15）

所有原始配置备份在服务器：`/home/ubuntu/_cfg_backup_20260715/`

```
system-lighthouse-chromium.service      改前的系统级服务
user-lighthouse-chromium.service        改前的 root 用户级服务
update-devtools-port.sh                 改前的端口脚本
backup_7day.sh                          改前的备份脚本
crontab-ubuntu.txt                      改前的 crontab
browser-existing-session.bak/           改前的 Chrome 会话目录（22M，含原登录态）
```

## 完整回滚（全部还原到修改前）

```bash
ssh ubuntu@124.220.64.8
B=/home/ubuntu/_cfg_backup_20260715

# 1) 还原 Chrome 服务与端口脚本
sudo systemctl stop lighthouse-chromium
sudo cp $B/system-lighthouse-chromium.service /etc/systemd/system/lighthouse-chromium.service
sudo cp $B/update-devtools-port.sh /usr/local/bin/update-devtools-port.sh
sudo chmod +x /usr/local/bin/update-devtools-port.sh
sudo systemctl daemon-reload
sudo systemctl start lighthouse-chromium

# 2) 还原 root 用户级服务（注意：它指向不存在的 chromium-1217，还原后会重新报 203/EXEC）
sudo cp $B/user-lighthouse-chromium.service /root/.config/systemd/user/lighthouse-chromium.service
sudo XDG_RUNTIME_DIR=/run/user/0 systemctl --user daemon-reload
sudo XDG_RUNTIME_DIR=/run/user/0 systemctl --user enable --now lighthouse-chromium

# 3) 还原 Chrome 会话目录（找回原登录态；注意该目录疑似已损坏，是崩溃的根源）
sudo systemctl stop lighthouse-chromium
sudo rm -rf /root/.openclaw/browser-existing-session
sudo cp -a $B/browser-existing-session.bak /root/.openclaw/browser-existing-session
sudo systemctl start lighthouse-chromium

# 4) 还原备份脚本与 crontab
cp $B/backup_7day.sh /home/ubuntu/backup_7day.sh
chmod +x /home/ubuntu/backup_7day.sh
crontab $B/crontab-ubuntu.txt      # crontab 本次实际未改动，仅为完整性提供
```
